# gotosleep-android

## Building

Before attempting to build this project, always read `README.md` for the current
build command, required `JAVA_HOME`, and `local.properties` setup. The default
system JDK often does not work — the README documents the JDK version and env
vars that actually succeed.

## Testing / running

Do not try to launch an emulator or otherwise run/test the app (no emulator
image or device is set up in this environment). Building (`assembleDebug`) is
fine and expected. The user tests the app themselves on their own device.
